## 4. Теоретическая часть

### 4.1. Алгоритм мини-макс

Мини-макс используется для выбора оптимального хода в играх, где есть
два игрока.

-   **MAX** старается получить как можно большее значение.
-   **MIN** старается получить как можно меньшее значение.

Игроки чередуются на каждом уровне дерева:

``` text
MAX
 ↓
MIN
 ↓
MAX
 ↓
MIN
```

Если MAX выбирает между значениями 20 и 50, он выберет 50.

Если MIN выбирает между значениями 20 и 50, он выберет 20.

### 4.2. Альфа-бета отсечение

Альфа-бета отсечение является оптимизацией алгоритма мини-макс.

Оно позволяет не проверять некоторые ветви дерева, если заранее понятно,
что они уже не смогут изменить итоговый результат.

Используются две переменные:

-   `alpha` --- лучшее найденное значение для MAX;
-   `beta` --- лучшее найденное значение для MIN.

Если выполняется условие:

``` text
beta <= alpha
```

оставшуюся часть текущей ветви можно не проверять.

При этом итоговый результат остаётся таким же, как у обычного мини-макс.

## 5. Реализация программы

Программа написана на языке **Python**.

``` python
import random
import time


# Количество проверенных узлов
minimax_nodes = 0
alphabeta_nodes = 0


# Глубина и ширина дерева
DEPTH = 6
WIDTH = 2


# Создание дерева
def create_tree(depth):
    """
    Создаёт игровое дерево.
    В листьях находятся случайные значения от -100 до 100.
    """

    # Если достигли листа
    if depth == 0:
        return random.randint(-100, 100)

    # Создаём WIDTH дочерних узлов
    children = []

    for _ in range(WIDTH):
        children.append(create_tree(depth - 1))

    return children


# Обычный мини-макс
def minimax(node, depth, maximizing_player):
    global minimax_nodes

    # Проверяем узел
    minimax_nodes += 1

    # Если дошли до листа
    if depth == 0:
        return node

    # Ход MAX
    if maximizing_player:
        best_value = float('-inf')

        for child in node:
            value = minimax(child, depth - 1, False)
            best_value = max(best_value, value)

        return best_value

    # Ход MIN
    else:
        best_value = float('inf')

        for child in node:
            value = minimax(child, depth - 1, True)
            best_value = min(best_value, value)

        return best_value


# Мини-макс с альфа-бета отсечением
def alphabeta(node, depth, maximizing_player, alpha, beta):
    global alphabeta_nodes

    # Проверяем узел
    alphabeta_nodes += 1

    # Если дошли до листа
    if depth == 0:
        return node

    # Ход MAX
    if maximizing_player:
        best_value = float('-inf')

        for child in node:
            value = alphabeta(
                child,
                depth - 1,
                False,
                alpha,
                beta
            )

            best_value = max(best_value, value)
            alpha = max(alpha, best_value)

            # Альфа-бета отсечение
            if beta <= alpha:
                break

        return best_value

    # Ход MIN
    else:
        best_value = float('inf')

        for child in node:
            value = alphabeta(
                child,
                depth - 1,
                True,
                alpha,
                beta
            )

            best_value = min(best_value, value)
            beta = min(beta, best_value)

            # Альфа-бета отсечение
            if beta <= alpha:
                break

        return best_value


# Основная программа

# Генерируем одно дерево
random.seed(42)
tree = create_tree(DEPTH)


# Обычный мини-макс
minimax_nodes = 0

start_time = time.perf_counter()

minimax_result = minimax(
    tree,
    DEPTH,
    True
)

minimax_time = time.perf_counter() - start_time


# Мини-макс с альфа-бета отсечением
alphabeta_nodes = 0

start_time = time.perf_counter()

alphabeta_result = alphabeta(
    tree,
    DEPTH,
    True,
    float('-inf'),
    float('inf')
)

alphabeta_time = time.perf_counter() - start_time


# Результаты
print("=== Результаты ===")

print(f"Глубина дерева: {DEPTH}")
print(f"Ширина дерева: {WIDTH}")

print()

print("Обычный мини-макс:")
print(f"Результат: {minimax_result}")
print(f"Проверено узлов: {minimax_nodes}")
print(f"Время: {minimax_time:.8f} секунд")

print()

print("Мини-макс с альфа-бета:")
print(f"Результат: {alphabeta_result}")
print(f"Проверено узлов: {alphabeta_nodes}")
print(f"Время: {alphabeta_time:.8f} секунд")

print()

print("Проверка результатов:")

if minimax_result == alphabeta_result:
    print("Результаты совпадают")
else:
    print("Результаты НЕ совпадают")
```

## 6. Объяснение программы

### 6.1. Подключение библиотек

``` python
import random
import time
```

`random` используется для генерации случайных значений листьев.

`time` используется для измерения времени выполнения алгоритмов.

### 6.2. Параметры дерева

``` python
DEPTH = 6
WIDTH = 2
```

`DEPTH = 6` означает глубину дерева 6.

`WIDTH = 2` означает, что каждый узел имеет два дочерних узла.

### 6.3. Генерация листьев

``` python
if depth == 0:
    return random.randint(-100, 100)
```

Когда программа доходит до последнего уровня, создаётся случайное целое
число от `-100` до `100`.

Например:

``` text
-45
72
13
-91
38
```

Таким образом выполняется условие варианта 3.

### 6.4. Рекурсивное создание дерева

``` python
for _ in range(WIDTH):
    children.append(create_tree(depth - 1))
```

Функция вызывает сама себя, уменьшая глубину на единицу:

``` text
depth = 6
   ↓
depth = 5
   ↓
depth = 4
   ↓
...
   ↓
depth = 0
```

Когда `depth` становится равным нулю, создаётся лист со случайным
значением.

### 6.5. Обычный мини-макс

При посещении каждого узла увеличивается счётчик:

``` python
minimax_nodes += 1
```

Если ход принадлежит MAX:

``` python
best_value = float('-inf')
best_value = max(best_value, value)
```

MAX выбирает максимальное значение.

Для MIN:

``` python
best_value = float('inf')
best_value = min(best_value, value)
```

MIN выбирает минимальное значение.

### 6.6. Альфа-бета алгоритм

Альфа-бета функция получает дополнительные параметры:

``` python
alpha
beta
```

Для MAX обновляется:

``` python
alpha = max(alpha, best_value)
```

Для MIN:

``` python
beta = min(beta, best_value)
```

После этого проверяется:

``` python
if beta <= alpha:
    break
```

Если условие выполняется, дальнейшая проверка ветви прекращается.

## 7. Измерение эффективности

Для измерения времени используется:

``` python
start_time = time.perf_counter()
```

После выполнения алгоритма:

``` python
time.perf_counter() - start_time
```

получается время работы.

Количество проверенных узлов считается с помощью:

``` python
minimax_nodes
alphabeta_nodes
```

Сравнение выполняется по следующим показателям:

  Показатель                    Мини-макс         Альфа-бета
  ------------------ -------------------- ------------------
  Результат                    одинаковый         одинаковый
  Проверенные узлы                 больше   меньше или равно
  Время                зависит от запуска      обычно меньше

Точное время выполнения зависит от компьютера и конкретного запуска.

------------------------------------------------------------------------

## 8. Почему используется одно дерево

Сначала создаётся одно дерево:

``` python
tree = create_tree(DEPTH)
```

После этого оно передаётся обоим алгоритмам:

``` text
                    Одно дерево
                         |
              +----------+----------+
              |                     |
           Minimax              Alpha-Beta
```

Это важно для корректного сравнения.

Если создавать разные случайные деревья для каждого алгоритма,
результаты нельзя было бы корректно сравнить.

------------------------------------------------------------------------

## 9. Зачем используется `random.seed(42)`

``` python
random.seed(42)
```

Эта команда делает последовательность случайных чисел воспроизводимой.

При повторном запуске программы будут использоваться те же значения
листьев.

Число `42` не имеет специального значения. Можно использовать другое
число.

Это удобно при сравнении двух алгоритмов, потому что оба всегда работают
с одинаковым деревом.

алгоритма мини-макс и одновременно уменьшить количество выполняемых
проверок.
